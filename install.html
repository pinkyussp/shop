How to install cursors

Install a cursor set in a few clicks on Windows. Video guide coming soon.

Video coming soon

Steps

  1. Unzip the download.
  2. Right-click install.inf and choose Install.
  3. Open Settings, search Mouse cursor, and pick the scheme (for Bunni, pick bunni).
  4. Click Apply.

Hornet only: open Mouse Properties, go to the Pointers tab, pick the Hornet scheme, and click Apply.
